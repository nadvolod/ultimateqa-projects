# social-posts

Auto-generated launch-post drafts, one Markdown file per project per platform.

Files are created by `.github/workflows/daily-project-scan.yml` in the form:

```
YYYY-MM-DD-<repo-slug>-linkedin.md
YYYY-MM-DD-<repo-slug>-x.md
```

Review, edit, and post manually from the PR that introduces them.
