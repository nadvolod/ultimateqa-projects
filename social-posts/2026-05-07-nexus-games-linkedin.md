# LinkedIn — Nexus Games - Workshop Chaos Sandbox

I built a chaos sandbox, and it's live.

Nexus Games – Workshop Chaos Sandbox started as a tool I needed for developer workshops: a place where you can throw UI chaos scenarios at a wall and see what sticks. No setup, no config headaches. Just open it and start breaking things intentionally.

The idea is simple. Developers learn better when they can experiment in a low-stakes environment. This gives you that — a live playground where chaos is the feature, not the bug.

It's fully open-source, deployed on Vercel, and ready to use right now. Whether you're running a workshop, stress-testing UI assumptions, or just curious what controlled chaos looks like in a browser — this is for you.

Live playground: https://nexus-games-seven-jade.vercel.app
Source: https://github.com/nadvolod/nexus-games
